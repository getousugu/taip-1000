# Typing Nexus (Exam Master)

AIが生成した日本語長文を課題に、リアルな検定環境でタイピングスキルを測定するWebアプリケーションです。

一般的なタイピングゲームとは異なり、**「試験」としての厳密さ**を最優先に設計されており、日本語タイピング検定（ビジネス能力検定タイピングなど）の実技に近い形式で練習が可能です。

---

##  主な特徴

### 1. 試験モードとしての厳密な設計
市場の多くのタイピングアプリとは一線を画し、本番の緊張感を再現するための工夫が施されています。
- **リアルタイムフィードバックの排除**: 入力中は正誤が表示されず、ハイライトも行われません。
- **初見の課題文**: 試験開始まで課題文の内容は分からず、試験中に初めて内容を確認しながら入力します。
- **事後採点方式**: 試験終了後に初めて、詳細な採点結果と差分ハイライトが表示されます。

### 2. AIによる動的な課題文生成
Groq APIを活用し、毎回異なる課題文を生成します。
- **暗記の防止**: 毎回文章が変わるため、純粋なタイピング速度を測定できます。
- **自由なジャンル設定**: IT、ニュース、SF小説など、練習したい語彙に合わせたカスタマイズが可能です。
- **難易度調整**: 初級（常用漢字中心）、中級（熟語・専門語）、上級（難読漢字・記号）の3段階から選択できます。

### 3. 高精度な採点アルゴリズム
**LCS（最長共通部分列）アルゴリズム**を独自に拡張して採用しています。
- **ミスの連鎖を防止**: 1文字の脱字で後続がすべてミスになることを防ぎ、文字の「順序的な一致」を正しく評価します。
- **前方マッチ優先**: タイピングの入力順（左から右）に合わせた自然な差分表示を実現しています。
- **詳細な分析**: 誤字（紫）、脱字（赤）、余過（黄）を色分けして表示し、自分の弱点を一目で把握できます。

##  技術スタック

- **Frontend**: Vite + React (JavaScript)
- **Styling**: CSS (Tailwind CSS等)
- **AI Engine**: Groq API (llama-3.3-70b-versatile 推奨)
- **Algorithm**: 独自拡張LCS (Longest Common Subsequence)
- **Deployment**: GitHub Pages

---

##  使い方

1. **APIキーの準備**: [Groq Console](https://console.groq.com/keys) で無料のAPIキーを取得し、アプリの入力欄に貼り付けます（開発者のキーを借りることも可能です）。
2. **試験設定**: 目標文字数、難易度、ジャンル、制限時間を設定します。
3. **試験開始**: 「試験開始」ボタンを押すとAIが課題文を生成します。
4. **タイピング**: 上部の課題文を見ながら、下の入力エリアに書き写します。
5. **結果確認**: 制限時間終了、または「試験終了」ボタンで採点画面へ進み、結果を確認します。

##  ランク判定基準

| ランク | 条件 |
| :--- | :--- |
| **S (金)** | KPM > 150 かつ 正確率 > 95% |
| **A (緑)** | KPM > 100 かつ 正確率 > 90% |
| **B (青)** | KPM > 50 かつ 正確率 > 80% |
| **C (灰)** | それ以外 |

> **KPM (Key strokes Per Minute)**: 正しく入力できた文字数 ÷ 経過時間（分）で算出される純速度です。

##  開発・デプロイ

### ローカル開発環境の構築
```bash
# リポジトリのクローン
git clone https://github.com/getousugu/taip-1000.git
cd taip-1000

# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

### デプロイ手順
Viteを使用してビルドし、GitHub Pagesに公開します。
```bash
# ビルドとデプロイの実行
npm run deploy
```
※ `vite.config.js` の `base` 設定がリポジトリ名と一致していることを確認してください。
